## คำที่ใช้บ่อยในเอกสารนี้

อ่าน 6 คำนี้ก่อน แล้วที่เหลือจะไม่สะดุด · ศัพท์อื่น ๆ อยู่ที่ [GLOSSARY_TH.md](./GLOSSARY_TH.md)


| คำ               | หมายถึง                                                                                                                                                         |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **chunk**        | ไฟล์วิดีโอสั้น ๆ ที่แอปอัดทีละไฟล์ · ที่ 4K ยาวประมาณ **10–12 วินาที** ต่อไฟล์ · แอปไม่อัดยาวไฟล์เดียวเพราะถ้าแอปดับกลางทาง ไฟล์ที่ยังไม่ปิดจะ**เปิดไม่ได้เลย** |
| **track**        | "หนึ่งครั้งที่ระบบมองเห็นคนหนึ่งคนต่อเนื่องกัน" · ยังไม่ใช่ "หนึ่งคน" เพราะคนเดียวที่เดินผ่านหลายรอบ = หลาย track                                               |
| **person ID**    | เลขประจำตัวที่ระบบแปะให้แต่ละคน เพื่อรู้ว่ากล่องในเฟรมนี้กับเฟรมก่อนเป็นคนเดียวกัน                                                                              |
| **frame / เฟรม** | ภาพนิ่งหนึ่งภาพจากวิดีโอ · ระบบไม่ได้ดูทุกเฟรม แต่**สุ่มดูทุก 120 มิลลิวินาที** (ประมาณ 8 ภาพต่อวินาที)                                                         |
| **candidate**    | รูปที่ระบบเซฟไว้ก่อนแบบ "อาจจะเก็บ" · สุดท้ายเลือกเก็บแค่ 3 รูปต่อคน ที่เหลือลบ                                                                                 |
| **baseline**     | ตัวเลข "ก่อนแก้" ที่เก็บไว้เทียบกับ "หลังแก้" · ไม่มี baseline = แก้แล้วพิสูจน์ไม่ได้ว่าดีขึ้น                                                                  |

### ⛔ S0.1 · "ตอนแอปสลับไฟล์ วิดีโอขาดไปนานเท่าไร"

**เรื่องมันเป็นแบบนี้:** แอปไม่ได้อัดวิดีโอยาวไฟล์เดียว มันอัดเป็นไฟล์สั้น ๆ ไฟล์ละ 10–12 วินาที แล้วสลับไฟล์ใหม่เรื่อย ๆ
**ตอนสลับไฟล์ จะมีช่วงสั้น ๆ ที่ไม่ได้อัดอะไรเลย** — เราต้องรู้ว่ามันนานแค่ไหน

**ทำไมต้องรู้:** ถ้านักวิ่งกำลังวิ่งผ่านอยู่ตอนที่แอปสลับไฟล์ ระบบจะเห็นเขาหายไปแวบหนึ่งแล้วโผล่มาใหม่ ⇒ ต้องเดาว่า "คนที่โผล่มา คือคนเดิมไหม"


| ขาดไปนานเท่าไร           | เดาได้ไหม                                               |
| ------------------------ | ------------------------------------------------------- |
| **น้อยกว่า 0.12 วินาที** | ✅ เหมือนหายไปแค่ภาพเดียว — เดาง่าย ทำ S9 ได้เลย         |
| **0.12–0.6 วินาที**      | ⚠️ ยังเดาได้ แต่ต้องระวังการตั้งค่า                     |
| **มากกว่า 0.6 วินาที**   | ⛔ **คนขยับไปไกลเกินจะเดาได้** — **ยกเลิก S9 ทั้ง task** |


**วิธีนับ** — เปิด `session_log.txt` แล้วเอาเวลาที่ไฟล์หนึ่งจบ (`recordedAtEpochMs` + `recordDurationMs`) ไปลบกับเวลาที่ไฟล์ถัดไปเริ่ม (`recordedAtEpochMs`)

# 📦 ก้อน 1 — บันทึกและหลักฐาน
